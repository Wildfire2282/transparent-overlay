# 透明悬浮窗 (TransparentOverlay)

Windows 桌面上的半透明置顶黑窗，可拖动、改透明度，位置、大小和透明度自动保存。

## 运行

- 双击 `TransparentOverlayV1.pyw`，或运行 `pythonw TransparentOverlayV1.pyw`
- 调试时用 `python TransparentOverlayV1.pyw` 启动，报错会直接显示在终端

## 操作

| 操作 | 效果 |
|------|------|
| 左键拖动窗口任意位置 | 移动 |
| 窗口边框 | 调整大小（系统原生） |
| 鼠标滚轮 | 调整透明度，每档 5%，范围 10%–100% |
| 右键 | 菜单：透明度、关于、退出 |
| 关于窗口按 Esc | 关闭 |
| 标题栏关闭按钮 | 保存配置并退出 |

## 配置

保存在 `%APPDATA%\TransparentOverlay\window_config.json`：

| 字段 | 含义 |
|------|------|
| x, y | 窗口左上角坐标，恢复时完整夹取到虚拟桌面内（支持多显示器负坐标） |
| width, height | 窗口尺寸，限制在 100 与桌面尺寸之间 |
| alpha | 透明度，范围 0.1–1.0 |

文件缺失、损坏或含非有限数值（如 Infinity/NaN）时自动回退默认值，不影响启动。配置先写临时文件再原子替换，写入中断不会留下半个文件。最小化/最大化状态下退出不会写配置。

## 分辨率适配

界面以 1080p / 96 DPI 为基准，按屏幕有效分辨率等比放大；小屏不缩小。窗口默认占屏幕 1/4。

| 分辨率（100% 缩放） | 界面缩放 |
|------|------|
| 1920×1080 | 1.00 |
| 2560×1440 | 1.33 |
| 3840×2160 | 2.00 |

系统 DPI 更高时，取 DPI 缩放与分辨率缩放中的较大值。关于窗口按内容自适应尺寸、在父窗口居中，并限制在桌面内。

## 代码结构

单文件 `TransparentOverlayV1.pyw`，只用标准库：

- `desktop_bounds`：读取扣除标题栏与边框后的虚拟桌面范围（多显示器），失败退回主屏
- `clamp_window_state` / `read_window_state` / `write_window_state` / `step_alpha` / `compute_ui_scale`：配置与几何逻辑，不依赖界面控件，可直接测试
- `OverlayApp`：界面与事件绑定
- `main`：启动

单文件，不拆包：拆分会增加维护面。
